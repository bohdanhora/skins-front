# SkinScout

Инструмент для поиска выгодных скинов CS2 на white.market, DMarket, CSFloat, lis-skins и Steam Market.
API лежит рядом, в `skins-back`.

## Запуск

```bash
cp .env.example .env.local
npm install
npm run dev
```

Открыть `http://localhost:3100`. Сервер `skins-back` должен быть запущен.

## Разделы

- **Выгодно**: три режима.
  - Где дешевле: один предмет, разные цены.
  - Перепродать: купить на одной площадке, выставить на другой. Прибыль уже без комиссии.
  - Продать сразу: купить на white.market и сразу продать по заявке на DMarket.
- **Топ предложения**: сравнение текущей цены с продажами за восемь недель, ликвидностью, заявками и глубиной рынка.
  Можно сортировать по силе сигнала, скидке, числу продаж или цене и оставить только площадку, на которой предмет
  сейчас дешевле.
- **Флоат, находки**: лоты, которые уже подходят под более дорогую заявку на DMarket по флоату, паттерну или фазе.
  Купил и сразу отдал в заявку. Кнопка «Проверить» открывает поиск с нужным диапазоном.
- **Флоат, поиск**: лоты DMarket, white.market и CSFloat в заданном диапазоне, заявки на автопокупку и отдельный блок
  Steam Market в валюте кошелька. Износ меняется одним переключателем с ценами соседних состояний.
- **Поиск**: любой предмет по словам из названия, фазе, износу, версии, коллекции и самой дешёвой площадке.
- **Наклейки**: цены на сами наклейки и поиск скинов с нужными наклейками (нужны ключи на сервере). Можно указать,
  на каком предмете искать: любой, часть названия («AK-47») или точный скин. По умолчанию сверху лоты, где за
  наклейку почти не доплачивают: цена сравнивается с самым дешёвым таким же скином и с ценой наклеек по отдельности.
- **Избранное**: сердечко на карточке, хранится в браузере. Можно сортировать.
- **Инвентарь**: открытый инвентарь Steam по ссылке на профиль. Для каждого предмета видно, сколько придёт на руки
  на каждой площадке после комиссии продажи и вывода, и итог по всему инвентарю.

У категорий оружия, ножей, перчаток и наклеек есть подкатегории: модель (AK-47, Karambit) или турнир. Во всех
списках есть сортировка по цене, частоте продаж и тому, насколько цена ниже истории продаж.

lis-skins участвует только как место покупки: продажу туда программа не предлагает.

В карточке предмета есть график за 2 или 8 недель: продажи white.market, DMarket и CSFloat отдельными линиями, текущие цены всех
площадок и заявка DMarket пунктиром. Линии включаются и выключаются в легенде. Ниже строка Steam Market: самый
дешёвый лот и медиана в долларах.

Каждая фаза Doppler и Gamma Doppler (Phase 1-4, Ruby, Sapphire, Emerald, Black Pearl) это отдельная карточка со своей
картинкой и ценами на всех площадках. Фаза написана рядом с названием.

Карточки честно предупреждают, если лотов или заявок мало или цена сильно выше той, по которой предмет реально скупают.

Комиссии продажи и вывода и тема меняются в настройках (шестерёнка справа сверху).
