# SkinScout

Сравнение цен на скины CS2 между white.market и DMarket: где купить дешевле и на чём можно заработать.
API лежит рядом, в `skins-back`.

## Запуск

```bash
cp .env.example .env.local
npm install
npm run dev
```

Открыть `http://localhost:3100`. Сервер `skins-back` должен быть запущен.

## Разделы

- **Выгодно**: три режима.
  - Где дешевле: один предмет, разные цены.
  - Перепродать: купить на одной площадке, выставить на другой. Прибыль уже без комиссии.
  - Продать сразу: купить на white.market и сразу продать по заявке на DMarket.
- **Топ предложения**: то, что сейчас продают дешевле, чем обычно покупали последние две недели, и дешевле, чем на
  второй площадке. Рядом видно, за сколько предмет скупают, то есть можно ли сразу выйти без убытка.
- **Флоат, находки**: лоты, которые уже подходят под более дорогую заявку на DMarket по флоату, паттерну или фазе.
  Купил и сразу отдал в заявку. Кнопка «Проверить» открывает поиск с нужным диапазоном.
- **Флоат, поиск**: выбираешь скин и диапазон флоата, получаешь самые дешёвые лоты в нём, доплату за флоат и заявки на
  автопокупку под этот флоат.
- **Поиск**: любой предмет по словам из названия, в любом порядке.
- **Наклейки**: цены на сами наклейки и поиск скинов с нужными наклейками (нужны ключи на сервере). Можно указать,
  на каком предмете искать: любой, часть названия («AK-47») или точный скин. По умолчанию сверху лоты, где за
  наклейку почти не доплачивают: цена сравнивается с самым дешёвым таким же скином и с ценой наклеек по отдельности.
- **Избранное**: сердечко на карточке, хранится в браузере.

В карточке предмета есть график продаж на DMarket за 2 или 8 недель.

Карточки честно предупреждают, если лотов или заявок мало или цена сильно выше той, по которой предмет реально скупают.

Комиссии площадок и тема меняются в настройках (шестерёнка справа сверху).
